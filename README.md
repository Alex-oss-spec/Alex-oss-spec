**What I've built**

Checked against 102 postcodes across the country before anyone saw it, and those checks are kept as a regression suite. Built with Claude Code, agent skills and MCP. The code is private, but I'm happy to walk through it.

Surface-aware Elo and Monte Carlo forecast of the Wimbledon 2026 men's draw, committed before the tournament started and scored against the real results afterwards. The favourite won, and three of the four predicted semi-finalists got there.
